GridPulse - how to run
======================

Needs: Java 17+, Node 20, Docker Desktop (or a local MySQL 8, see "Manual MySQL").


0. Secrets
----------
   cp springapp/secrets.properties.example springapp/secrets.properties
   fill in the keys you have (empty = that feature is off). never push this file.
   an environment variable with the same name wins over the file.

   other settings (env vars, all optional):
   SERVER_PORT                     backend port, default 8080
   DB_HOST / DB_PORT               mysql, default localhost / 3306 (ignored when DB_URL is set)
   JWT_SECRET                      64+ characters; empty = a key file in ~/.gridpulse (one instance only)
   GRIDPULSE_JOBS_REFUND_ENABLED   false = no refund job here (run it on one instance only)
   FRONTEND_URL                    where the Angular site runs, default http://localhost:8081
                                   (the admin invite email links to FRONTEND_URL/set-password)
   REDIS_HOST / REDIS_PORT         redis for the cache, default localhost / 6379
   CACHE_TYPE                      none = run without redis (no cache); default redis


1. Infra with Docker (MySQL + Redis + Kafka + Kafka UI)
-------------------------------------------------------
   cp .env.example .env            (MYSQL_ROOT_PASSWORD, MYSQL_PORT)
   docker compose up -d
   docker compose ps               every container "healthy" after about a minute

   DB_PASSWORD in springapp/secrets.properties = MYSQL_ROOT_PASSWORD in .env (both "examly" by default)

   MySQL     localhost:3306  (schemas appdb, payment_db, ai_db, notification_db)
   Redis     localhost:6379
   Kafka     localhost:9092 for apps on this machine, kafka:29092 for containers
   Kafka UI  http://localhost:8090

   stop:            docker compose down
   stop + wipe db:  docker compose down -v

   Manual MySQL (alternative): any MySQL 8 on localhost:3306, login DB_USERNAME / DB_PASSWORD
   (default root / examly). appdb is created on the first backend start.


2. Backend (http://localhost:8080)
----------------------------------
   needs MySQL and Redis running (step 1; only these two: docker compose up -d mysql redis)
   from the repo root (one Maven build for all modules):
   ./mvnw -q install -DskipTests -pl common        (only after a change in common/)
   ./mvnw -pl springapp spring-boot:run

   no Redis at hand: CACHE_TYPE=none ./mvnw -pl springapp spring-boot:run   (works the same, without the cache)
   check the cache: docker compose exec redis redis-cli keys 'gp:*'

   health:   http://localhost:8080/actuator/health        {"status":"UP"}, details with an admin token
   swagger:  http://localhost:8080/swagger-ui.html        (not in prod)
             log in on /api/admin/login (or /api/login), copy "token", press Authorize, paste it
   /actuator/info and /actuator/metrics need an Admin / SuperAdmin token


3. Frontend (http://localhost:8081)
-----------------------------------
   cd angularapp
   npm install
   npm start


4. Tests (Docker must be running, nothing else)
-----------------------------------------------
   cd springapp
   ./mvnw verify

   the tests start their own throw-away MySQL, never touch appdb and send no email
   (texts go to springapp/target/test-mails, logs to springapp/target/test-logs). Razorpay is faked,
   the cache is off (no Redis needed for the tests).
   14 tests: two drivers paying for the same car number at once, one order confirmed twice,
   two admins approving the last seat at once, 401 / 403 rules, competition start guard,
   approval email in the background, admin list pages (paging + query count), admin invite link,
   circuit breaker, driver stats + leaderboard after a full competition.
   one class only:  ./mvnw test -Dtest=StatsIntegrationTest
   skip them:  ./mvnw package -DskipTests
